===== ble-doctor  =====
Cross-platform BLE diagnostics and security CLI

Usage: ble-doctor [OPTIONS] <COMMAND>

Commands:
  scan          Scan for BLE devices
  analyze       Analyze a capture or device
  sniff         Ingest a BLE sniffer (Sniffle) stream and judge MAC rotation; needs sniffer hardware for --device
  fingerprint   Device fingerprint: LE+GATT profile (+ SDP/LMP on Linux)
  probe-writes  Probe writable characteristics (EMPIRICAL: connects without bonding and writes)
  read-values   Read characteristic values on non-SIG services (lists length + preview only)
  dfu           Probe DFU surface (EMPIRICAL buttonless probe: writes to the device without bonding)
  doctor        Diagnose the local BLE environment
  mcp           Run the MCP server
  recon         Recon a target (native GATT inventory)
  ctf           CTF helpers (own-gear / CTF scope only; never reachable via `mcp`)
  baseline      Baseline snapshots
  handoff       Export a handoff bundle
  rules         Inspect rules
  why           Explain a finding (rule doc, plus the finding from a report JSON)
  mitm          GATT MITM: clone the target as a peripheral and relay+log traffic to/from it (Linux + 2 adapters + peripheral mode only; EMPIRICAL/active)
  help          Print this message or the help of the given subcommand(s)

Options:
      --adapter <ADAPTER>  Local Bluetooth adapter (e.g. hci0). Linux only; ignored elsewhere
  -h, --help               Print help
  -V, --version            Print version
===== ble-doctor scan =====
Scan for BLE devices

Usage: ble-doctor scan [OPTIONS]

Options:
      --adapter <ADAPTER>        Local Bluetooth adapter (e.g. hci0). Linux only; ignored elsewhere
      --target <TARGET>          Target address / identifier / name (or set BLE_DOCTOR_TARGET) [env: BLE_DOCTOR_TARGET=]
      --timeout <TIMEOUT>        Scan duration in seconds [default: 5]
      --mtu <MTU>                Request exactly this ATT MTU from --target (a BLE address; Linux only)
      --as-address <AS_ADDRESS>  Connect to --target presenting this BLE address (LE Set Random Address; Linux only)
      --json                     Emit the doctor/1 JSON envelope (needs --target)
      --tui                      Show the findings in an interactive terminal UI (needs --target)
      --sarif <SARIF>            Write a SARIF 2.1.0 report to this file (needs --target)
      --baseline <BASELINE>      Diff findings against a saved doctor/1 `--json` report; exit 3 if NEW failures reach --fail-on
      --fail-on <FAIL_ON>        Exit 1 (3 with --baseline, new findings only) when a finding is at or above this severity [default: high] [possible values: info, low, medium, high, critical]
  -h, --help                     Print help

===== ble-doctor ctf =====
CTF helpers (own-gear / CTF scope only; never reachable via `mcp`)

Usage: ble-doctor ctf [OPTIONS] <COMMAND>

Commands:
  brute            Write 0x00..=0xff to --char one byte at a time, reading --read-char back after each write, until the read-back contains --contains
  read-n           Read a characteristic `n` times in a row
  write-then-read  Write a value, then read a (possibly different) characteristic back
  help             Print this message or the help of the given subcommand(s)

Options:
      --adapter <ADAPTER>  Local Bluetooth adapter (e.g. hci0). Linux only; ignored elsewhere
  -h, --help               Print help
===== ble-doctor ctf brute =====
Write 0x00..=0xff to --char one byte at a time, reading --read-char back after each write, until the read-back contains --contains

Usage: ble-doctor ctf brute [OPTIONS] --target <TARGET> --char-uuid <CHAR_UUID> --read-uuid <READ_UUID> --contains <CONTAINS>

Options:
      --adapter <ADAPTER>      Local Bluetooth adapter (e.g. hci0). Linux only; ignored elsewhere
      --target <TARGET>        Target address / identifier / name (or set BLE_DOCTOR_TARGET) [env: BLE_DOCTOR_TARGET=]
      --char-uuid <CHAR_UUID>  Characteristic UUID to brute-write
      --read-uuid <READ_UUID>  Characteristic UUID to read back after each write
      --contains <CONTAINS>    Stop once the read-back value contains this substring (ASCII)
      --timeout <TIMEOUT>      Scan/connect timeout in seconds [default: 5]
  -h, --help                   Print help
===== ble-doctor ctf read-n =====
Read a characteristic `n` times in a row

Usage: ble-doctor ctf read-n [OPTIONS] --target <TARGET> --char-uuid <CHAR_UUID>

Options:
      --adapter <ADAPTER>      Local Bluetooth adapter (e.g. hci0). Linux only; ignored elsewhere
      --target <TARGET>        Target address / identifier / name (or set BLE_DOCTOR_TARGET) [env: BLE_DOCTOR_TARGET=]
      --char-uuid <CHAR_UUID>  Characteristic UUID to read
      --n <N>                  Number of reads [default: 1]
      --timeout <TIMEOUT>      Scan/connect timeout in seconds [default: 5]
  -h, --help                   Print help
===== ble-doctor ctf write-then-read =====
Write a value, then read a (possibly different) characteristic back

Usage: ble-doctor ctf write-then-read [OPTIONS] --target <TARGET> --char-uuid <CHAR_UUID> --data <DATA> --read-uuid <READ_UUID>

Options:
      --adapter <ADAPTER>      Local Bluetooth adapter (e.g. hci0). Linux only; ignored elsewhere
      --target <TARGET>        Target address / identifier / name (or set BLE_DOCTOR_TARGET) [env: BLE_DOCTOR_TARGET=]
      --char-uuid <CHAR_UUID>  Characteristic UUID to write
      --data <DATA>            Bytes to write, as hex (e.g. "01ff")
      --read-uuid <READ_UUID>  Characteristic UUID to read back
      --timeout <TIMEOUT>      Scan/connect timeout in seconds [default: 5]
  -h, --help                   Print help
